# 状态机与并发审查报告（子 agent 原始产出）

审查范围：§2（房间/断线）、§5（排便/打断）、§6（主任）、§7（技能）、§9（状态机）、§10~12（结算/观战/防挂机）。tick 基准：服务器 20Hz，1 tick = 50ms，故 6s=120 tick、2s=40 tick、1.5s=30 tick，所有整秒引导都会恰好落在整数 tick 上，同帧碰撞是常态而非极端情况。

### [S1] 主任入住目标未排除已占用隔间；无候选隔间时行为未定义
**事件序列**：t=40s 主任登场 roll 命中。此刻隔间1=玩家A大便中（无障碍）、隔间2=玩家B占而不排（无障碍）、隔间3=巨蟒障碍。"无障碍隔间"候选集={1,2}，两间均有人。按 §6 字面"入住一个随机无障碍隔间"，主任与 A/B 同处一间：出现双占用者，占用标志归谁、骚扰值/逼出对主任是否生效、嗅闻返回什么全部崩坏。若实现层改为静默放弃入住，则 60% 登场承诺无声破产，"嗅闻识主任"玩法整局蒸发。5 人局 25~70s 窗口内 3 间全占或无障碍间全占的概率相当高（障碍率 35%+保底 1 间意味着无障碍间常只有 1~2 间）。
**文档现状**：缺失。§6 仅写"随机**无障碍**隔间"，未排除有人；未定义候选为空时的行为；§5.2 占用体系（进入即红标、仅占用者解除、裁决#3 强制解除）与"主任驻留 15~30s"在同一隔间上不可共存。
**建议裁决**：候选集 = 无障碍且无人；为空则每 5s 重 roll 直至入住或 300s 到时（到时则本局主任取消，不补偿）；二进宫沿用同一规则。

### [S1] 排便/善后状态下的断线语义自相矛盾；POST（善后）期间忍耐是否扣减未定义
**事件序列**：玩家A 隔间大便至 80% 断线。§2.3"状态保留"——进度继续还是冻结？若继续：A 免操作白嫖剩余时长（唯一反制是他人凑满骚扰值逼出，5 人局未必有人管），"断线保护排便"成最优策略；若冻结：A 卡在 100% 无纸 POST 时断线，喊话/破罐破摔均无法执行，30s 后必判负。更硬的矛盾：§2.3"忍耐值**照常扣减**" vs §3 表"排便中流失 0（暂停）"——照常按哪档？步行档则断线比在线排便更亏；按排便档（0）则断线免流失。连带未定义：**POST 状态本身忍耐是否恢复扣减**（暂停=无纸者可赖到 300s 占死隔间；恢复=无纸者是死亡倒计时，两种是完全不同的游戏）。再叠加：断线 30s 超时判负与瞌睡 30s 判负对同一具身体同 tick 到期，谁先触发、是否双扣奖励。
**文档现状**：歧义+矛盾。§2.3、§3、§9 三处互不衔接；§9 状态机无 POST 的断线分支，也无 POST 忍耐规则。
**建议裁决**：断线瞬间服务端强制中断排便（进度 -50% 冻结，身体置于隔间内站位），忍耐按步行档扣减；POST 期间忍耐恢复扣减（制造递纸压力）；瞌睡计时器在断线期间冻结，判负权归断线计时器独占；重连后 3s 霸体。

### [S2] 全部 1.5~3s 引导动作的"判定采样时点"（开始时 vs 完成时）未定义
**事件序列**（典型链）：t=100.0 玩家C 对隔间2 启动撬锁（2s，完成于 t=102.0）。t=100.8 主任二进宫入住刚空出的隔间2（无障碍无人，合法）。t=102.0 撬锁完成：按"完成时采样"→C 当场抓获判负（C 全程无感知、无任何可读线索）；按"开始时采样"→C 撬开空门后**物理走入**主任隔间算不算闯入？同构竞态至少还有六种：引导中目标占用者主动出门/被逼出/炸裆（铁丝梯子白扣？骚扰+2 挂谁？）；嗅闻 1.5s 中目标换人（情报按哪一刻快照，嗅出的是前任？）；递纸 1.5s 中受纸者被逼出（纸给谁）；清障碍 3~5s 中第三人进入该隔间；翻墙 3s 中主任离场；冲水伪装对"视觉空、实际占用"（假贴所致）隔间交互失败——失败本身构成占用真值预言机。
**文档现状**：缺失。§5.2/§5.3/§7.2 只给时长；裁决#5 只管"同帧"，完全不管"跨帧的目标漂移"。
**建议裁决**：统一"完成时采样，目标失效即中断"：引导中目标占用状态变化→引导中断、撬锁/翻墙道具不消耗、骚扰值不清算；唯一例外明写死——完成瞬间目标为主任→判负照常生效（保留"假贴+二进宫"这类组合技的节目效果，但必须成文）。

### [S2] 逼出"让渡"语义空洞：远程逼出者不在场、标志转移时点、第三人竞速
**事件序列**：玩家D 持扫把在走廊隔门捅满 3 次骚扰→占用者E 逼出（硬直2s）。tick N 逼出结算时 D 距隔间 8m。§5.2"隔间让渡给闯入者"——占用标志此刻归 D？则隔间红灯但 D 要 8s 后才走到：期间玩家F 走进去算抢夺还是非法进入？若服务器拒绝 F，D 获得可无限期挂机的远程产权（比"占而不排"更恶）；若逼出瞬间标志清空、先到先得，则"让渡"一词无意义，且与裁决#3"仅占用者主动出门解除"冲突（此刻不存在占用者）。同 tick 还有：撬锁引导在骚扰满 3 同帧完成，让渡给持扫把者还是持铁丝者？§5.2"按服务器 tick 序"只回应了多人争抢，未回应标志归属。附带同洞：清障碍 3~5s 期间隔间占用标志是否置位（清障者可被捅/逼出吗）。
**文档现状**：已有裁决但有问题——裁决#3 与 §5.2"让渡给闯入者"互不衔接，且未定义时点、远程逼出场景、清障占用。
**建议裁决**：逼出瞬间标志强制回绿；给"贡献最后一击骚扰者"一个 2s 进入优先锁（仅本人进入生效，超时释放）；此刻指向该隔间的撬锁/翻墙引导立即视为完成并享受优先；清障碍期间置占用标志，清障者可被正常骚扰/逼出。

### [S2] tick 内处理顺序与状态转移优先级未定义（裁决#5 只说"串行"，没说"怎么串"）
**事件序列**：t=6.000（tick 120）玩家A 小便池进度恰好 100%；同 tick 到达：B 的推搡、C 对 A 的嗅闻完成、A 的霸体到期。完成优先→A 退场观战、B 的 CD 白扣？打断优先→A 整 6s 白排？同构还有：两人同 tick 进同一空隔间（后序者意图失效，给不给失败反馈、会不会卡门）；两人同 tick 向同一受纸者递纸完成（第二张纸退不退、+10 发不发、受纸者"立即完成"触发两次？）；同一扇门撬锁（2s）与翻墙（3s）不同 tick 启动却同 tick 完成（骚扰 +2+2=4>3，逼出结算给谁、让渡给谁）；霸体 2s 内到达的第二次推搡（丢弃还是排队）。同 tick 多输入的确定性排序也未定义，直接影响回放一致性。
**文档现状**：已有裁决但有问题——裁决#5 与 §5.2"按服务器 tick 序"只承诺"有序"，未承诺顺序规则、优先级与确定性。
**建议裁决**：tick 内固定三级流水：①定时器结算（完成/炸裆/主任离场/定型）②在途引导推进 ③本 tick 新意图（按 actor_id 确定性排序）；同级内"定型/完成"优先于"打断"；同门双引导同帧完成→骚扰叠加、让渡给先启动者；第二张递纸整体回滚（纸退、无 +10、提示"手慢"）；同 tick 双进入→先序者得、后序者收到明确"已被占用"反馈。

### [S2] 重连快照的信息边界未定义：主任位置泄露（正向）与断线者情报真空（反向）
**事件序列**：玩家A t=50 断线（主任在场，驻留至 t=68）。t=60 A 重连，"服务器快照恢复"。快照含隔间占用真值→A 直接知道哪间是主任（在线玩家须花嗅闻或冒判负风险换取的隐藏信息，断线者白得，且可语音外传）；快照不含→A 对主任存在一无所知，而 30s 断线窗与主任 15~30s 驻留在时间上高度重叠，A 盲撬任一间即高概率无知情判负。快照是否重放断线期间错过的公开广播（离场哼歌）也未写。
**文档现状**：缺失。§2.3/§13 只有"JWT 重鉴权→状态快照恢复"一句；§6 明确主任身份占用指示"与玩家无异"属全局隐藏信息，两者从未对齐。
**建议裁决**：快照 = 自身状态 + 公开信息（自身位置、各隔间**视觉**指示、已广播事件重放）；不含占用真值、不重放任何主任独占信息；重连给 3s 霸体 + 表现层提示"刚断线，谨慎闯入"。

### [S2] 定型（DONE/BLOWOUT/判负）后到达的判负与交互是否改写定型未定义
**事件序列**：t=79.9 玩家A 捅门（主任在场，25% roll 命中，"破门而出"需要演出窗口）；t=80.0 A 自己的隔间大便 100%+持纸→DONE 定型退场观战；t=80.2 主任破门演出落地。判负是否追杀已 DONE 者？追杀→A 从"完成者按用时"桶被改判进"判负者"桶，排名瞬间跳变；15s 延迟流的观战者看到 A 先胜利退场再被拖走的矛盾画面。同构：判负者在途的 1.5s 递纸是否照常送达；300s 到时 tick 与打断/定型同帧。
**文档现状**：缺失。§9 把 DONE/BLOWOUT/判负并列为"定型"，§10 按定型类型排名，但全文无"定型后新事件"处理规则；§6 判负触发也未规定与目标退场的先后。
**建议裁决**：定型即封闭——本 tick 定型后，任何后续指向该玩家的交互/判负一律丢弃（递纸者不消耗纸、判负不追杀）；判负 roll 改为操作 tick 即时结算，破门演出纯表现层，不参与逻辑窗口。

### [S2] 3s 准备倒计时中的断线未定义；开局雕像触发双重判负计时器同 tick 撞车

### [S3] 同账号双设备同房：30 天 Access Token 使"异设备吊销"拦不住并发在线
**事件序列**：账号X 在设备A 登录（获 30 天 Access Token，进房准备）；又在设备B 登录——Refresh 异设备复用触发吊销全部 Token，但 A 的 Access Token 仍剩 29 天，**连接不断**。B 输同一房号：同账号二次加入是顶替 A 的成员资格（按账号去重）还是占第 2 个坑（按连接去重，4 个账号即满 5 人锁）？对局中 B 顶号→A 被踢→A 的 Token 已吊销、重连必须密码重登，实际必判负——盗号/共享账号者可用此机制狙击真人。
**文档现状**：已有裁决但有问题。§2.1 吊销仅针对 Refresh 复用，不针对并发 Access；§12"同设备多账号限制"未定义限制内容；§2.2 未定义房间成员按账号还是连接去重。
**建议裁决**：房间成员与对局槽位严格按账号去重，同账号重复加入=顶替旧连接；异地登录踢旧连接时，若旧连接在对局中给 15s 抢占宽限（宽限期内判负计时暂停，每局限 1 次防滥用）。

### [S3] 观战 15s 延迟 < 主任最长驻留 30s；延迟流与全场结束/集锦的衔接未定义
**事件序列**：A t=60 炸裆观战（15s 延迟流）。t=100 主任入住隔间2；t=115 A 的延迟流才播到 t=100——A 语音告知队友，主任 t=115~130 才离场：情报仍有 0~15s 可操作窗口，约半数情况下防报点失效（§12 自己承认组队狙击是威胁）。结尾衔接：最后一名玩家 t=280 定型→逻辑上全场结束，观战流才播到 t=265——结算画面立即弹给定型者而观战者看 15s 死画面？还是全场等延迟流追平（活人多干等 15s）？炸裆集锦从延迟直播流还是服务器权威回放生成、观战者看到的炸裆顺序与最终排名是否可能不一致？
**文档现状**：缺失。§11 仅"15s 延迟"一句；§10 结算与集锦无任何延迟流对齐说明；§16.3 自问"15s 是否过长"但没找对方向——问题是相对主任驻留时长，不是绝对值。
**建议裁决**：二选一：延迟 ≥35s，或观战流对主任隔间表现打码（与在场玩家可见信息对齐即可）；全场定型后观战流 3 倍速追平再统一弹结算；集锦一律从服务器权威回放生成，与结算时刻统一。

### [S3] 骚扰值的归属实例与重置规则未定义
**事件序列**：玩家A 占隔间被捅至骚扰值 2。A 被逼出，B 让渡入主——B 继承残留的 2（一次捅门即被逼出，极不公平）还是清零？若清零："仅占用者主动出门解除"意味着 A 出门 1s 再进自己那间即免费洗仇恨，循环白嫖。主任二进宫入住同一间后，若实现按"隔间"存骚扰值，历史值会误伤新占用者；对主任隔间捅门是先 +1 骚扰再判负，还是判负不落地？骚扰值是否随时间衰减也未写。
**文档现状**：缺失。§5.2 只定义"满 3 逼出"，未定义数值挂载对象（占用者/隔间/攻击者对）与任何重置时机。
**建议裁决**：骚扰值挂"占用实例"（占用者×隔间），占用标志任何一次翻转（主动出门、逼出、判负、炸裆、断线超时、清障开始）即销毁；不随时间衰减；对主任隔间的骚扰类操作在判负结算时不落地骚扰值。

### [S4] 小便池没有任何占用/互斥语义
**事件序列**：玩家A 池2 排便中（t=2/6s），玩家B 走进同一池位开始排便——红/绿指示、"仅占用者解除"、裁决#3 强制解除整套体系全部只针对隔间；两人同池并行、进度互不影响、第三人推搡谁、软碰撞把谁挤出均无规则。§4.2"入口视野区：可直视全部小便池 occupants"暗示单池单 occupant，但规则层从未落地。
**文档现状**：缺失。§5.2 占用条款仅覆盖隔间；§4.2 小便池无占用说明。
**建议裁决**：池位比照隔间：进入即占用、离开/打断退出即释放；第二人进入请求服务器拒绝并给反馈；断线/炸裆/判负时强制释放，同裁决#3。
