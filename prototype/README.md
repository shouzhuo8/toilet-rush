# 课间特急：厕所攻防战 — 可玩原型 v0.1

网页原型（免安装，手机/电脑双端可玩）：你 + 4 个 AI 同学，完整对局循环。

## 玩法与操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧虚拟摇杆 |
| 交互（拾取/进坑/捅门/撬锁/递纸…） | Q | 右侧「交互」键 |
| 技能（嗅闻 / 涡轮增压） | E | 右侧「技能」键 |
| 道具（憋气糖 / 假指示贴） | F | 右侧「道具」键 |
| 取消引导 / 弃坑 | X 或 Esc | 右侧「取消」键 |
| 冲水伪装（试探假贴/主任间） | R | 「冲水」键 |
| 光屁股出门（无纸时）/ 取纸 / 洗手 | POST 弹窗第 3 键、Q、R | 同左（弹窗大按钮） |
| 疾跑（按住） | Shift | 移动模式切换键 |
| 潜行（按住） | Ctrl | 移动模式切换键 |

善后（卡 100% 无纸时）弹三个大按钮：**喊话要纸** / **光屁股出门** / **破罐破摔(+5s)**。
光屁股出门后进入 10s 限时移动态（移速 ×0.6），可：①去有纸的空隔间直接取纸（0.5s，干净完成 0 惩罚）；**有人的有纸房持梯子/铁丝直接翻入取纸（不骚扰、不逼出、原占用者不受影响），取纸后沿原路爬出完成**；②走到洗手台洗手（1.5s，「优雅结束」+5s）；③超时自动破罐（+8s）。别人递纸仍 = 0 惩罚。
