# 课间特急：厕所攻防战 — 可玩原型 v0.1

网页原型（免安装，手机/电脑双端可玩）：你 + 4 个 AI 同学，完整对局循环。

## 玩法与操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧虚拟摇杆 |
| 交互（拾取/进坑/推搡/捅门/撬锁/递纸…） | Q | 右侧「交互」键 |
| 技能（嗅闻 / 涡轮增压） | E | 右侧「技能」键 |
| 道具（使用憋气糖等） | F | 右侧「道具」键 |
| 取消引导 / 弃坑 | X 或 Esc | 右侧「取消」键 |
| 疾跑（按住） | Shift | 移动模式切换键 |
| 潜行（按住） | Ctrl | 移动模式切换键 |

善后（卡 100% 无纸时）会弹出两个大按钮：**喊话要纸** / **破罐破摔(+5s)**。

## 规则来源

数值与规则完全来自 `../GDD-PVP.md` v0.3（17 条设计裁决），交互结算按 `../arch/ARCH-9.5-引导结算协议.md` 实现（20Hz 单机模拟 = 服务端逻辑同构）。

## v0.1 范围说明（有意裁剪）

- 单机：你 + 4 个 AI（信息可见性边界 ARCH-13.2 对 AI 生效，对渲染不裁剪——全图可见是原型便利，多人版收紧）
- 已含：3 路径与全部道具（口罩/扫把/铁丝/梯子/搋子/纸/漫画/憋气糖）、4 种排便、打断/骚扰/逼出、主任全套（60% 登场/闯入判负+推门可撤/30% 激怒）、嗅闻（误判方向加权/传染）、善后与递纸、90s 预备铃 + 软收尾 + 180s 上限、尿王/屎王双榜
- 暂缺（后续版本）：假指示贴（信息层欺骗）、冲水伪装、洗手彩蛋、观战电视台、多人联机（后端走 fishio 同款 WSS 架构）
